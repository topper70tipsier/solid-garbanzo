# solid-garbanzo

A simple HTML calculator built with plain HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear, percent, sign toggle, and decimal support
- Responsive dark-themed layout
- Works directly in the browser

## Run it locally

1. Open `index.html` in your browser, or
2. Serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Files

- `index.html` — calculator markup, styling, and logic
